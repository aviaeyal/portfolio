HONEYBOOK · IA · 2023

Library Folders

How do you bring order to a growing library of templates and files without adding friction to everyday use?

The shipped Library — folders in the left rail, All/Images/Files filtering, and a selection toolbar for bulk actions.

ROLEProduct designer
TEAMPM · engineering · research
TIMELINE2023
CONTRIB.Research → ship

CONTEXT

The library was one unorganized, flat list. Users had to scroll through every image and file with no way to filter or group assets — there was no folder, tag, or category to lean on.

Finding one specific image became a time-consuming, frustrating process — and that friction compounded every time someone needed to reuse a template or asset.

BEFORE — everything in one flat list, images and files mixed together with no way to group them.

PROCESS

I designed a folder model that lets people group assets their own way, plus a right-click menu covering the everyday actions — rename, move, remove from a folder, set as a project header, delete — so reorganizing didn't mean touching every item one at a time.

Right-click on any asset for the full set of folder actions, scoped to the folder it's currently in.

“It maps to how I already think about my business, not how the software thinks.”

— CARD-SORT PARTICIPANT

OUTCOME

Shipped a hierarchical folder system with bulk move and organize actions across the library.
