Library Folders

How do you bring order to a growing library of templates and files without adding friction to everyday use?

The shipped Library: folders in the left rail, All/Images/Files filtering, and a selection toolbar for bulk actions.

ROLEProduct designer
TEAMPM · engineering · research
TIMELINE2026
SCOPEScoping → ship

CONTEXT

The library was one unorganized, flat list. Users had to scroll through every image and file with no way to filter or group assets, and there was no folder, tag, or category to lean on.

Finding one specific image became a time-consuming, frustrating process, and that friction compounded every time someone needed to reuse a template or asset.

BEFORE: everything in one flat list, images and files mixed together with no way to group them.

#1community-requested
fix, for years
300members opening the
Library every week

PROCESS

I modeled the new folders on the pattern members already knew from Templates, so the mental model wouldn't be new twice. The harder part wasn't the folder concept, it was consistency: the Library opens from seven separate places across the product, from the Tools tab to an email attachment picker to a Smart File thumbnail, and folders needed to behave identically in every one of them. I designed the model and a right-click menu covering the everyday actions (rename, move, remove from a folder, set as a project header, delete) so reorganizing didn't mean touching every item one at a time, then we shipped it in stages, first internally, then to 20% of members, then 30%, watching for the rough edges a single entry point wouldn't have surfaced before opening it to everyone.

Right-click on any asset for the full set of folder actions, scoped to the folder it's currently in.

OUTCOME

Shipped a hierarchical folder system with bulk move and organize actions, rolled out gradually across the library's seven entry points to all members and trialers.
